## Gate rule

JSON Schema MUST NOT be frozen until the open Phase 0 design questions are resolved and the resulting object semantics pass adversarial architecture review.

## Normative language

The key words MUST, MUST NOT, SHOULD, SHOULD NOT, and MAY are used as normative terms. Each MUST / MUST NOT requirement is expected to map to at least one future conformance test.
